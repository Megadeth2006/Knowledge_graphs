# Граф знаний для подбора съёмного жилья

Григорьев Даниил (465635), Михайлов Петр (466730). ИТМО, «Графы знаний», 2026.

Локальный поиск сопоставляет требования арендатора с объявлениями на Петроградском острове. Граф связывает цену и условия с датированной карточкой, квартиру — со зданием, а здание — с проверенной точкой OpenStreetMap.

## Запуск

В каталоге `rental_kg` с подготовленным окружением Windows выполнить в Git Bash:

```bash
.venv/Scripts/python.exe search_app.py
```

Открыть [локальный поиск](http://127.0.0.1:8765/). В PyCharm можно запустить `search_app.py` с тем же интерпретатором. На новой машине сначала создать окружение и установить зависимости:

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

## Демонстрация

- **Protégé.** Открыть `observed_with_ontology.owl`. С HermiT на вкладке DL Query выбрать Instances. Выражение `'Квартира' and 'расположено в' value 'Санкт-Петербург'` возвращает 11 квартир. Учебный граф с вымышленными экземплярами — `demo_with_ontology.owl`.
- **Поиск.** Срез «Экотона» от 26.11.2026 содержит пять предложений. При бюджете 220 000 ₽ и восьми минутах пешком подходят Ропшинская, 4 и Подковырова, 11–13. При пятнадцати минутах добавляются Малая Посадская, 17 и Большая Посадская, 12. На странице «Запросы и SHACL» можно выполнить обычный и пространственный запросы и увидеть диагностику испорченной учебной записи.
- **Воспроизведение.** `.venv/Scripts/python.exe build_graph.py` собирает графы из локальных CSV и снимка OSM, проверяет OWL RL, SHACL и восемь ответов SPARQL. Результаты записываются в `results/`. Интернет требуется только для отдельного обновления каталога.
