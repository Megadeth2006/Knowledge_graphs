# Граф знаний для подбора съёмного жилья с учётом требований арендатора

**Команда:** Григорьев Даниил (465635), Михайлов Петр (466730). ИТМО, «Графы знаний», 2026.

## Модель и данные

1. Объяснимый подбор долгосрочной аренды целой квартиры в Санкт-Петербурге по бюджету, условиям и окружению.
2. Подготовлены реальные данные: 6 вручную нормализованных карточек с URL и датой чтения 22.10.2026. Это малый пилот, а не полный рынок. Одно объявление ограничено четырьмя месяцами и не проходит фильтр долгосрочной аренды.
3. Онтология версии 1.1.0: 15 классов, 12 объектных свойств и 23 атрибута, русские метки и определения классов, домены, диапазоны, иерархия, инверсия, транзитивность и непересекаемость.
4. Отдельно создан воспроизводимый синтетический набор: 12 объявлений, 6 точек инфраструктуры, 72 измерения расстояния. Ни один из этих объектов не выдаётся за реальное жильё или объект OSM.
5. Восемь компетентностных вопросов и восемь SPARQL-запросов с проверяемыми ответами; сборка RDF, вывод OWL RL и SHACL.

`Place` объединяет адресные контейнеры `City`, `District`, `Building`. Предмет аренды описывает отдельная ветвь `Dwelling → Apartment`, а объекты окружения — `Amenity → MetroStation, Supermarket, Park`. Координаты хранятся у зданий и объектов инфраструктуры. Расстояние от квартиры рассчитывается по точке её здания.

Реальный пилот используется для запросов об условиях аренды. Проверка расстояний опирается на отдельно помеченный синтетический набор. Реальная инфраструктура OSM, проверенная геопривязка, пешеходные маршруты и обучение представлений относятся к дальнейшему развитию.

## Запуск

Python 3.10 или новее. Из каталога проекта:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate
python -m pip install -r requirements.txt
python build_graph.py
```

Скрипт работает локально, не обращается к сайтам, заново формирует `.ttl`, `.owl` и файлы `results/`. Версии зависимостей зафиксированы по среде, где проверен запуск. Исходные CSV не изменяются.

Сборка проверяет вывод обратной связи и нахождения жилья в городе, сохранение отдельных ролей жилья и инфраструктуры, SHACL и ответы всех восьми запросов. Отрицательные примеры проверяют обнаружение неверной цены, несовместимых типов, пространственных связей и координат.

## Просмотр и результаты

Для просмотра схемы и учебных экземпляров в Protégé откройте `demo_with_ontology.owl`. Файл содержит исходные утверждения, поэтому обратные отношения и нахождение квартиры в городе можно получить запуском reasoner. Программная сборка выполняет соответствующие проверки в OWL RL.

Даты представлены как `xsd:date`, поскольку известен календарный день. Этот тип отсутствует в стандартной карте типов OWL 2. Плагин HermiT 1.4.3.456 в Protégé включает игнорирование неподдерживаемых типов: вывод отношений работает, однако календарная семантика дат этим запуском не проверяется. Обычный запуск HermiT без этой настройки отклоняет модель. Это ограничение переносимости текущей схемы; наличие данных о дне не означает известного времени суток. [OWL 2: Time Instants](https://www.w3.org/TR/owl2-syntax/#Time_Instants).

Запрос долгосрочной аренды до 40000 руб./месяц возвращает реальное объявление `R02`. Учебный запрос с разрешением на животных и метро не далее 1000 м возвращает `D06`, `D09`, `D12`. Неизвестные условия не считаются выполненными. Полные ответы находятся в `results/query_results.json`, сводка сборки — в `results/summary.json`.
